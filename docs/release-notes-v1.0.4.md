First public release of Image Deduper.

## Downloads

- **Windows x64:** `ImageDeduper-Windows-x64-Setup.exe`
- **Apple Silicon Mac:** `ImageDeduper-macOS-arm64.zip`
- **Intel Mac:** `ImageDeduper-macOS-x64.zip`
- **Checksums:** `SHA256SUMS.txt`

## Features

- Recursive or single-folder scanning
- Exact byte-size and pixel-dimension matching
- Side-by-side image previews
- Oldest file protected automatically
- Select-all and per-file deletion controls
- Cancellable scans with partial results
- Optional creation-time difference filter
- Optional minimum file-size filter
- Revalidation immediately before permanent deletion

## Before installing

These builds are currently unsigned. Windows may show SmartScreen and macOS may
show an unidentified-developer warning. Only download this app from this GitHub
repository. See the [installation and troubleshooting guide](https://github.com/designlook/image-deduper#install).

Deletion is permanent and does not use the Recycle Bin or Trash. Review every
selection and back up important folders before confirming.
